# SYSU_Philosophy_Entrance_Exam
## 项目介绍
本项目用于整理和检索中山大学哲学考研相关资料。

## 在线使用

公开检索网站：
[https://lemizou.github.io/SYSU_Philosophy_Entrance_Exam/](https://lemizou.github.io/SYSU_Philosophy_Entrance_Exam/)

打开网址后可以直接按关键词、年份、科目、题型和标签检索。检索条件会保存在
网址中，复制当前链接即可分享同一组结果。

目标：
- 整理历年考试真题
- 建立知识分类体系
- 实现关键词检索
- 开发AI辅助系统

## 网页检索说明

Windows 可双击项目根目录的 `启动检索.cmd`，也可以在终端运行：

```powershell
启动检索.cmd
```

关键词支持空格 AND、`OR`、引号短语和前置减号排除：

```text
康德 先验
康德 OR 黑格尔
"哥白尼转向"
康德 -黑格尔
```

完整组合规则见 `docs/search-semantics.md`。

左侧“索引筛选”可按人物、流派、时期、主题和著作浏览标签。标签支持搜索、
多选，并显示各标签对应的题目数量。同一分类中选中多个标签时，命中任意一个
即可；跨分类条件需要同时满足。

检索结果和试题详情也会显示相同的分类标签。点击标签即可加入筛选，再次点击
即可取消；左侧索引会同步切换到对应分类。

使用关键词检索时，结果会标明命中了题干、材料还是标签，并高亮实际命中的
正向关键词。材料命中会在结果列表中显示首个命中位置附近的上下文。

检索条件带支持起止年份、题型和结果排序。相关度按题干、标签、材料依次赋予
较高到较低的权重；没有正向关键词时自动按年份从新到旧显示。
题型按每份原卷中的出现顺序统一为“第一类”“第二类”“第三类”，不再混用
“简答”“释词”“论述”等历年不同名称。

关键词、标签及全部结构化筛选会同步写入浏览器网址。刷新、前进后退或复制
当前链接重新打开，都会恢复同一组检索条件。

桌面端的检索结果与试题详情并排显示，中间分隔线可以拖动调整宽度；也可用
方向键微调，或双击恢复默认比例。移动端改为“检索结果／题目详情”页签，
点击一道题后自动切换到详情，标签筛选则使用横向滚动的紧凑布局。

当前数据量下继续采用项目内的零依赖检索实现。与 MiniSearch、ItemsJS 的中文
正确性和性能对比，以及未来重新评估第三方检索库的条件，见
`docs/search-engine-evaluation.md`。

## 标签数据

题目标签已经分为哲学家、流派、时期、主题和著作五类，规范名称及别名记录
在 `data/tag_taxonomy.json`。修改标签后可运行以下命令检查题目与标签表是否
一致：

```powershell
python src/validate_tags.py
```

分类原则和维护方式见 `docs/tag-taxonomy.md`。

## 自动测试

本地运行全部数据校验、Python 测试和 JavaScript 测试：

```powershell
python tests/run_all.py
```

`.github/workflows/tests.yml` 会在推送、拉取请求及手动触发时运行同一套检查。
完整验收矩阵、Chrome 端到端检查和失败排查见
[`docs/testing.md`](docs/testing.md)。
