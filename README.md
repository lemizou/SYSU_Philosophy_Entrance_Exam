# 中山大学哲学考研历年真题检索

本项目整理中山大学中国哲学史、外国哲学史历年考研真题，并提供零依赖的网页
检索界面和 Python 命令行工具。

当前题库收录 431 道题，覆盖 2003—2026 年（暂缺 2007 年）。题目可按关键词、
年份、科目、题型和知识标签组合检索。

## 在线使用

[打开公开检索网站](https://lemizou.github.io/SYSU_Philosophy_Entrance_Exam/)

网页支持：

- 空格 AND、OR、引号短语和前置减号排除；
- 在左侧索引中按年份、人物等分类多选筛选，或使用“全卷概览”阅读完整试卷；
- 按哲学家、流派、时期、主题和著作标签组合筛选；
- 按相关度或年份排序，并高亮题干、材料及标签命中位置；
- 将完整检索条件写入网址，方便刷新、返回和分享；
- 桌面端可调节结果与详情栏宽度，移动端提供结果与详情页签；
- 在“考点统计”页按科目、年份、题型和标签类别查看年度分布、高频考点与
  年度热力表，并可跳转到对应原题；桌面端采用固定视口和面板内滚动，移动端
  保留纵向页面滚动以确保全部内容可达。

关键词示例：

```text
康德 先验
康德 OR 黑格尔
"哥白尼转向"
康德 -黑格尔
```

完整规则见 [检索语义说明](docs/search-semantics.md)。

## 本地运行

Windows 用户可以双击 `启动检索.cmd`，或在项目根目录运行：

```powershell
启动检索.cmd
```

也可以直接使用 Python 启动本地网页：

```powershell
python src/search_web.py
```

服务默认运行在 `http://127.0.0.1:8765/`，并自动打开浏览器。若端口被占用，
可通过 `--port` 指定其他端口。

命令行检索示例：

```powershell
python src/search.py 笛卡尔
python src/search.py "康德 先验" --year-from 2015 --subject 外国哲学史
python src/search.py --help
```

## 数据与分类

- `data/questions.json`：结构化真题数据；
- `data/tag_taxonomy.json`：标签规范名称、分类及别名；
- `docs/tag-taxonomy.md`：标签分类与维护规则；
- `docs/section-classification.md`：历年题型的三分类规则；
- `docs/extraction-review.md`：真题提取与校对记录。

题型按每份原卷中的出现顺序统一为“第一类”“第二类”“第三类”，避免混用
“简答”“释词”“论述”等历年不同名称。来源和文字仍需核实的题目通过校对
状态及备注字段明确记录，不自行补写。

修改题目或标签后，先运行：

```powershell
python src/validate_tags.py
```

## 测试

运行完整的数据校验、Python 测试、JavaScript 测试和 Chrome 端到端测试：

```powershell
python tests/run_all.py
```

完整验收范围和故障排查见 [自动测试与验收](docs/testing.md)。GitHub Actions
也会在推送和拉取请求时运行同一套检查。

## 项目结构

```text
data/       真题与标签数据
docs/       检索、分类、校对、测试及路线图文档
src/        Python 检索、校验和本地网页启动工具
tests/      Python、JavaScript 与浏览器端到端测试
web/        静态检索网页
index.html  GitHub Pages 项目入口
```

## 合作邀请

欢迎对哲学考研资料整理感兴趣的朋友参与合作。你可以参照本项目的数据结构、
分类方法与校对规范，整理其他大学哲学系（院）的历年考研真题，并通过 GitHub
Issue 或 Pull Request 与我们联系。经核对和适配后，相关题库可以合并进本项目，
参与整理、校对或开发的合作者也将作为项目贡献者予以记录。

随着收录院校和项目内容的扩展，项目名称及相关说明后续也可能根据实际内容进行
调整。无论是提供真题来源、补充缺失年份、交叉校对文本，还是改进数据、检索与
展示功能，都欢迎参与。
