# 标签体系

## 目的

题库原先把哲学家、流派、时期和问题主题统一放在 `philosophers` 字段中，
导致界面无法准确显示“哲学家标签”，也无法按不同类别组合筛选。

现在每道题使用五类标签：

| JSON 字段 | 标签类型 | 示例 |
| --- | --- | --- |
| `philosophers` | 哲学家或人物组合 | 康德、孔子、二程 |
| `schools` | 流派或思想传统 | 道家、经验论、宋明理学 |
| `periods` | 历史时期或思想运动 | 中世纪哲学、启蒙运动 |
| `topics` | 问题或研究主题 | 身心问题、自由意志 |
| `works` | 著作 | 当前旧标签中尚无著作标签 |

`data/tag_taxonomy.json` 是规范标签与别名的中央登记表。题目记录只能使用
其中的规范名称，检索器则应把别名转换为规范名称后再查询。

## 本次规范化

以下旧标签作为别名保留，但不再直接写入题目记录：

| 旧标签 | 规范标签 |
| --- | --- |
| 安瑟伦 | 安瑟尔谟 |
| 奥康 | 奥卡姆 |
| 佛学 | 佛教 |
| 黄老道家 | 黄老之学 |
| 宋明理学-其他 | 宋明理学 |
| 西方哲学史-综合 | 西方哲学史综合 |

题目原文不会随标签规范化而改写。例如原题使用“安瑟伦”或“奥康”时，
`question` 仍保留原卷文字，只有检索标签采用规范名称。

## 维护规则

1. 新标签必须先登记到 `data/tag_taxonomy.json`。
2. 同一标签只能属于一种类型。
3. 题目只能使用规范标签，异名放入中央标签表的 `aliases`。
4. 同一道题内不得重复使用同一标签。
5. 暂时无法可靠判断类型的标签，不应直接写入题库，应先人工确认。
6. 每次修改标签后运行：

   ```powershell
   python src/validate_tags.py
   ```

## 迁移脚本

`src/migrate_tags.py` 记录了旧标签到分类标签的迁移规则。默认运行只预览：

```powershell
python src/migrate_tags.py
```

只有显式传入 `--write` 时才会改写数据：

```powershell
python src/migrate_tags.py --write
```
