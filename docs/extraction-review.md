## 校对原则

1. 原始正式试卷优先于回忆版和汇编版。
2. 完整材料页优先于只有题目摘要的页面。
3. 两个来源一致时标记为“已交叉核对”。
4. 来源之间表述不同时，保留各自原文并标记差异，不擅自合并。
5. OCR 只生成初稿；古文、外国人名、书名和引文必须回看页面。

## 建议的最小数据格式

正式录入时，每一道题单独保存：

```json
{
  "id": "sysu-western-2024-short-01",
  "year": 2024,
  "subject": "外国哲学史",
  "section": "第一类",
  "number": 1,
  "question": "如何理解康德的“哥白尼转向”",
  "sources": [
    {
      "file": "中山大学 外国哲学史基础.pdf",
      "page": 5
    },
    {
      "file": "中大西哲真题（03-24.pdf",
      "page": 28
    }
  ],
  "verification": "cross_checked"
}
```

材料题可以把题干和材料原文放在同一条记录中；如果材料过长，再增加
`passage` 字段，不必一开始设计更复杂的数据库。

  成原文。
