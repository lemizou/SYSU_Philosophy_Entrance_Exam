年（暂缺 2007 年）的中国哲学史、外国哲学史试题。GitHub Pages 已发布，
当前重点是继续验收公开网站并补充缺失来源。

- [x] 将所有年份、科目的题型统一为第一类、第二类和第三类

整理时遵循以下原则：

1. 原始正式试卷优先于回忆版和汇编版。
2. 保留年份、科目、题号和来源页码；题型按原卷出现顺序归入三类。
3. 材料题的材料原文存入 `passage` 字段。
4. 双来源核对后使用 `cross_checked`；只有一个来源时使用
   `single_source`。
5. 无法确认的文字不自行补写，使用 `transcription_note`、
   `source_note` 或校对状态记录。
